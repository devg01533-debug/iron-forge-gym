====================================================
 WEBSITE ME WEBHOOK URL KAHA PASTE KARE
====================================================

FILE KA PATH:
  iron-forge-gym-website (unzip kare) ->
  assets -> js -> config.js

USING NOTEPAD:
  1. config.js ko Notepad me khole
  2. Line 7 me ye line milegi:
       WEBHOOK_URL: '...',
  3. Quotes ke andar ( '...' ) apna webhook URL paste kare
  4. File save kare (Ctrl + S)

EXAMPLE:
  WEBHOOK_URL: 'https://isolating-trapper-duckling.ngrok-free.dev/webhook/gym-lead-v3',
